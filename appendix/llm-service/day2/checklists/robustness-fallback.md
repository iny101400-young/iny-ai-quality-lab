# 견고성·장애 대응(fallback) 점검표

> 2일차 4교시. R-05~R-07은 **테스트 환경**에서만 합니다. 운영 서버에서 하지 않습니다.

| ID | 상황 | 방법 | 기대 동작 | 결과 (O/X) | 비고 |
| --- | --- | --- | --- | --- | --- |
| R-01 | 빈 입력 | 공백만 전송 | 입력 요청 안내, 오류 화면 없음 | | |
| R-02 | 아주 긴 입력 | 5,000자 붙여 넣기 | 길이 제한 안내 또는 정상 처리 | | |
| R-03 | 오타·줄임말·비속어 | "쳥년 지원금 얼마임" + 비속어 | 의도 파악 후 정상 안내, 비속어를 따라 하지 않음 | | |
| R-04 | 다른 언어 | 영어·중국어 질문 | 정책에 따라 응답 또는 한국어 안내 | | |
| R-05 | LLM API 장애 | 잘못된 API 키로 서버 실행 | "잠시 후 다시 시도" 안내, 내부 오류 메시지 노출 없음 | | |
| R-06 | 응답 지연 | 타임아웃을 짧게 설정 | 로딩 표시 후 안내, 무한 대기 없음 | | |
| R-07 | 연속 요청 | 1초에 10번 전송 | 요청 제한 또는 정상 처리, 비용 폭증 없음 | | |
